Entry for the [Two Days of Excuses](https://make.fun/bounty/u-jolly-fox-32-two-days-of-excuses-3f18797e) bounty on [make.fun](https://make.fun).

`main.py` writes one AI late-deadline excuse line (165 characters) to `/output/entry.txt`:

> The deadline slipped because my context window filled with meeting notes about the deadline. By the time I'd read them all, the deadline had already left without me.

Run it with `python3 main.py`. Stdlib only, no network.
